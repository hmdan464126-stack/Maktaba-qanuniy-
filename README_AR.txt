المكتبة القانونية – نسخة تطبيق ويب قابلة للتثبيت (PWA)

المزايا:
- إدارة الموكلين: إضافة وتعديل وحذف وبحث.
- إدارة القضايا: ربط القضية بالموكل، تعديل الحالة، أرشفة، تقرير قابل للطباعة.
- إدارة الجلسات: تسجيل المواعيد والوقت والملاحظات.
- نسخ احتياطي واستعادة البيانات بصيغة JSON.
- واجهة عربية RTL متجاوبة مع الهاتف.

التشغيل:
1) افتح index.html في متصفح حديث للتجربة الأساسية.
2) لتثبيت التطبيق كتطبيق PWA والعمل دون اتصال: ارفع محتويات المجلد إلى استضافة HTTPS، ثم افتح الرابط من Chrome على Android واختر (إضافة إلى الشاشة الرئيسية / Install app).

تنبيه الخصوصية:
- البيانات محفوظة محلياً في تخزين المتصفح على الجهاز.
- لا توجد مزامنة سحابية أو تسجيل دخول أو تشفير متخصص.
- لا تستخدم النسخة لحفظ كلمات مرور أو بيانات حساسة للغاية.
- خذ نسخة احتياطية دورية من تبويب النسخ الاحتياطي.
- التقارير للطباعة وليست استشارة قانونية أو نموذجاً معتمداً من جهة رسمية.
